# A clearer starting point

Hybrid infrastructure connects local computing, cloud services, and the operating
practices between them. InTheFog brings projects and practical documentation together
so you can find the next useful step.

## Choose your starting point

- [Azure Local](azure-local.md): planning and operating distributed infrastructure.
- [Hyper-V private clouds](hyper-v.md): estate discovery, capacity, design, and automation.
- [Azure Arc](azure-arc.md): connecting infrastructure to Azure management capabilities.
- [Hybrid operations](hybrid-operations.md): discovery, monitoring, resilience, and automation.

The [project directory](/projects/) links to each project's current home and documentation.
Those destinations remain authoritative for installation instructions and supported behavior.
