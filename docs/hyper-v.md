# Hyper-V private clouds

A private cloud starts with a clear view of workloads, compute, storage, networking,
availability, and the way the environment will be operated. Inventory the current estate
before choosing a target architecture or migration approach.

## Discover before designing

[Hyper-V Surveyor](https://labs.hybridsolutions.cloud/hyperv-surveyor/) helps explore
an existing environment. [Hyper-V Trailwright](https://labs.hybridsolutions.cloud/hyperv-trailwright/)
supports design decisions and configuration inputs. Review each project's maturity and
documentation before using its outputs in delivery work.

Connect design to day-two concerns: monitoring, recovery, patching, capacity growth,
and repeatable automation. The [operations guide](hybrid-operations.md) links shared tools.

For product guidance, use [Microsoft's Hyper-V overview](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/overview).
