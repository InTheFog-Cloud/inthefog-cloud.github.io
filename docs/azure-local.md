# Azure Local

Azure Local brings Azure-connected infrastructure to distributed locations. A useful
starting point is understanding the workloads, available hardware, networking, operational
ownership, and the services that need to run close to your users and data.

## Plan, design, operate

Begin with the [Azure Local community portal](https://azurelocal.cloud/) for existing
planning, implementation, operations, and service guidance. Use discovery and sizing
tools to inform a design, then verify the result against current product requirements.

[Azure Local Trailwright](https://labs.hybridsolutions.cloud/azurelocal-trailwright/)
explores architecture choices. The
[Hybrid Infrastructure Toolkit](https://labs.hybridsolutions.cloud/hybrid-infra-toolkit/)
provides patterns for repeatable labs and automation.

For supported product behavior and requirements, consult
[Microsoft's Azure Local documentation](https://learn.microsoft.com/en-us/azure/azure-local/).
