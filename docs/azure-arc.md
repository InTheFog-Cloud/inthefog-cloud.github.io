# Azure Arc

Azure Arc connects resources outside Azure to Azure management capabilities. It can help
bring distributed infrastructure into a shared operating model while workloads remain
in their existing locations.

## Connect with a purpose

Start with the management outcome: inventory, policy, monitoring, security, or service
delivery. Identify connectivity and identity requirements, operational ownership, and
the capabilities supported by the resource type you intend to connect.

[AzureScout](https://labs.hybridsolutions.cloud/azure-scout/) helps explore Azure resource
inventory and dependencies. The [project directory](/projects/) groups related discovery
and automation work.

Use [Microsoft's Azure Arc documentation](https://learn.microsoft.com/en-us/azure/azure-arc/)
for supported resource types, onboarding requirements, and current product guidance.
