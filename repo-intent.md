# Repo intent - inthefog-cloud.github.io

**Public front door for InTheFog hybrid cloud projects and documentation.**

Owned by Kristopher Turner / Hybrid Cloud Solutions. Serves infrastructure engineers,
architects, and contributors exploring Azure Local, Hyper-V private clouds, Azure Arc,
and hybrid operations and automation.

Owns the Docusaurus website, approved introductory documentation, public project catalog,
brand assets, and GitHub Pages deployment for inthefog.cloud. Existing projects retain
their repositories and authoritative documentation locations.

Public source is the approved exception to InTheFog's private-by-default policy.
Issues are disabled; confidential planning and delivery issues stay in private operations.
The catalog is curated, never generated from private tracker or registry data.

Consumes base HCS standards through the Governance MCP. The central platform owns
standards and shared tooling; this public portal has an explicit Docusaurus exception.
